Island Peak Base Camp

A dusty camping ground beside the Imja Glacier moraine, two to three hours beyond Chhukung. Trekkers walk up for the day; climbers sleep here before the pre-dawn start on Island Peak (Imja Tse).

Also written Imja Tse Base Camp, Pareshaya Gyab
