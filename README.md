# diggajupadhyay.github.io

This repository is published with GitHub Pages.

| Path | What it is |
|---|---|
| [`/trekksewa-demo/`](trekksewa-demo/) | **TrekkSewa**, a trekking companion for Nepal. Live at <https://diggajupadhyay.github.io/trekksewa-demo/>. |
| `404.html` | The not-found page GitHub Pages shows for any missing address. Missing pages inside the demo are sent to its own not-found page. |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are. |

Nothing is published at the root address. The TrekkSewa site is generated from the source in
[`trekksewa-demo/_src/`](trekksewa-demo/_src/). See the
[README there](trekksewa-demo/_src/README.md) for how to edit content and rebuild.
